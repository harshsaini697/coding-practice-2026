# Core Pattern Families

| Family | Learn These First |
|---|---|
| Linear data | Arrays, Strings, Linked Lists |
| Search space | Binary Search, Backtracking, BFS, DFS |
| Optimization | Greedy, Heap, DP |
| Relationships | Trees, Graphs, Union Find, Topological Sort |
| Prefix-like data | Trie, Prefix Sum, Rolling Hash |
